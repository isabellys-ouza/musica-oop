# musica-oop

Projetinho feito para praticar Programação Orientada a Objetos em Java, durante o curso **"Java: aplicando orientação a objetos"** (Alura).

Não é um app completo nem um sistema real, é só um espaço para eu treinar o que estou aprendendo com um tema que gosto (música).

## O que o projeto tem

Um catálogo simples com músicas e podcasts, exibido em um menu no console.

## Conceitos de POO aplicados

- **Classes e objetos**
- **Encapsulamento**
- **Construtores** e this
- **Herança** 
- **Classe abstrata** 
- **Interface** 
- **Sobrescrita de métodos** 
- **Polimorfismo** 

## Estrutura

```
com/github/isabellys_ouza/musicaoop/
├── Main.java
├── interfaces/
│   └── Exibe.java
└── model/
    ├── Audio.java
    ├── Musica.java
    └── Podcast.java
```

## Como rodar

Basta compilar e executar a classe `Main` em qualquer IDE Java (testado no IntelliJ).
